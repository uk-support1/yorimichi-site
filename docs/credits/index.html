写真について・クレジット

このサイトの写真は、すべてイメージです。実際の事業所、利用者、職員の写真ではありません。開設後、事業所の様子が分かる写真に順次差し替えます。

写真は、無料で商用利用できる写真素材サイト Unsplash(Unsplashライセンス) の作品を使用しています。撮影者のみなさんに感謝します。
