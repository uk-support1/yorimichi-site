寄り道の時間は、
自分を思い出す時間。

休職、離職、ブランク、思うようにいかなかった働き方。その経験は、失敗ではなく、これからの働き方を自分で選ぶための材料です。就労移行支援事業所「よりみち」は、その時間に一緒に立ち会う場所をつくっています。

「よりみち」という名前

遠回りは、迷子ではありません。

経験は、材料になる

うまくいかなかった職場、休んだ時間、家で過ごした日々。そこには「自分に合うこと・合わないこと」の手がかりが詰まっています。

正解は、支援者が決めない

進路も働き方も、決めるのはあなたです。私たちは選択肢を増やし、あなたと環境の間を調整する役割を担います。

就職だけがゴールではない

自分に合う働き方を知り、必要な助けを求められること。それが、働き続けるための土台になると考えています。

「できた」の数え方

小さな「できた」を、ちゃんと数える。

「自分にもできる」という感覚は、大きな成功より、日々の小さな経験から育つと私たちは考えています。よりみちでは、こんなことも「できた」として大切にします。

  • 自分で選べた
  • やってみた
  • 工夫できた
  • 休憩を選べた
  • 相談できた
  • 助けを求められた
  • 人の役に立てた
  • やめると決めた
5つの道しるべ

順番は決めません。行き来しながら進みます。

よりみちの支援は、次の5つの道しるべでできています。固定の順番や期間はありません。体調や気持ちに合わせて、戻ってもいいし、立ち止まってもいい。

  1. 安心と自己理解

    安心できる場と関係をつくり、自分の状態・特性・強み・大切にしたいことを知っていく。

  2. 小さな一歩

    自分で選んだ小さな行動を試し、「やってみた」「できた」を積み重ねる。

  3. 役割と実践

    模擬就労や役割の経験を通して、工夫や学びを手に入れる。

  4. 自分らしい進路

    自分に合う仕事・働き方・必要な配慮を整理し、企業実習や就職活動へ。

  5. 働き続けるための伴走

    困ったときの対処と、助けを求める力を育て、就職後も続く関係を持つ。

5つの道しるべを詳しく見る
私たちがしないこと

お約束していること、できないこと。

  • 進路を代わりに決めませんあなたの希望を起点に、一緒に整理します。
  • 結果は保証しません就職や定着を約束することはできません。約束するのは、力を尽くして伴走することです。
  • 体調の波を、努力不足にしません調子が悪い日は失敗ではなく、調整のヒントです。
  • 自己開示や発表を強制しません振り返りの方法は、複数から選べるようにします。
  • 誰かと比べません学び合いは大切にしますが、比較や競争にはしません。
