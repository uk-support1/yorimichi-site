よくある質問

よりみちについて

いつ開所しますか?

現在は開設準備中で、開所日は決まっていません。決まり次第、「お知らせ」と「事業所情報」に掲載します。

見学や相談はできますか?

受付の準備が整い次第お知らせします。それまでの間も、お住まいの市区町村の障害福祉窓口や相談支援事業所で、就労移行支援について相談できます。

診断名がないと利用できませんか?

利用できるかどうかは、お住まいの市区町村が判断します。障害者手帳をお持ちでなくても、医師の意見書などにより利用できる場合があります。まずは市区町村の窓口に確認してください。よりみちでは、診断名だけで支援の内容を決めることはしません。

就職を保証してもらえますか?

就職や職場への定着をお約束することはできません。よりみちがお約束するのは、あなたが自分の希望や強み、必要な配慮を理解し、自分で選べるよう、力を尽くして伴走することです。

就職以外の道を選んでもいいですか?

もちろんです。就職だけを唯一のゴールとは考えていません。働き方や進路は、あなたが選ぶものです。

制度について

就労移行支援とは何ですか?

就労を希望する65歳未満の障害のある人で、通常の事業所に雇用されることが可能と見込まれる人に、職場体験などの活動の機会や就労に必要な知識・能力を高める訓練、求職活動の支援、職場の開拓、就職後の定着のための相談などを行う障害福祉サービスです。

どのくらいの期間、利用できますか?

標準の利用期間は2年間です。必要と認められた場合には、更新により最大3年まで支給決定されることがあります。詳しくは市区町村にご確認ください。

利用料はいくらですか?

サービス費用の原則1割が自己負担ですが、世帯の所得に応じて月額の上限が決まっています。生活保護世帯・低所得世帯は0円、一般1は9,300円、一般2は37,200円が上限です。多くの方は上限額の範囲内、または0円での利用になります。事業所ごとに別途かかる費用(昼食代・交通費など)は、決まり次第掲載します。

利用するには、どんな手続きが必要ですか?

市区町村への申請と、支給決定を受けて「受給者証」の交付を受ける手続きが必要です。相談支援事業所で「サービス等利用計画」を作成します。流れは「制度と利用の流れ」のページで説明しています。

「就労選択支援」とは何ですか?

2025年10月に始まった障害福祉サービスです。就労アセスメントの手法を使って、本人の希望や力、適性に合った就労先・働き方の選択を支えます。就労移行支援を新しく使う際に必要かどうかは、市区町村にご確認ください。
