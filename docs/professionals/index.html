FOR PARTNERS

ご家族・関係機関・
企業の方へ

よりみちがどんな考え方で支援するのかを、お伝えします。連携の具体的な方法は、開設準備の中で整えています。

支援の基本姿勢(共通)

  • 本人が主役です。進路や働き方は、本人が選びます。支援者は、選択肢を増やし、本人と環境の間を調整します。
  • 診断名だけで支援を決めません。体調、生活の状況、困りごと、本人の希望を出発点にします。
  • 環境の側も調整します。ミスや疲れの原因を、本人の努力や能力だけに求めません。
  • 連携は、本人の同意を大切にします。情報の共有は、目的と範囲を本人と確認したうえで行います。
  • 結果は保証しません。就職や定着を約束するのではなく、本人が納得して選べるよう力を尽くします。

ご家族の方へ

心配な気持ちを、大切なものとして受け止めます。そのうえで、よりみちは、ご本人が自分で選び、試し、「自分にもできる」と感じられる経験を重ねられるよう支援します。ご家族と共有する内容や方法は、ご本人の意向を尊重して相談しながら決めます。

相談支援事業所・医療機関・行政の方へ

体調の波への配慮、活動量の調整、必要な配慮の整理などで、本人の同意のもと連携させていただきます。

  • 固定の順番・期間を設けず、体調や希望に応じて行き来できる支援設計
  • 相談や休憩、援助要請も含めて「できた」を記録し、自己理解に役立てること
  • 本人と環境の両面から調整する視点

連携の窓口、受け入れ・紹介の方法などは、開設準備中です。決まり次第、こちらに掲載します。

FOR COMPANIES

企業の方へ

実習や採用を検討いただく企業の皆さまに向けて、よりみちでは、本人が「自分に必要な配慮」を自分の言葉で説明できるよう、働き方ガイド(自分の取扱説明書)づくりを支援します。指示の出し方や環境の調整など、具体的な工夫を共有することで、本人にとっても企業にとっても、無理のない働き方を探ります。

企業との連携先・実習の受け入れ実績は、現時点ではありません。連携のご相談窓口は、開設準備が整い次第お知らせします。
